# ts-monorepo-template

## Introduction

This repository provides a template to simplify creating
new TypeScript NPM packages in a Git monorepo.

A monorepo is a way to include multiple related packages
inside the same parent project, though having multiple
is technically optional.

You can access the project
[here](https://github.com/Crow281/ts-monorepo-template).

## Setup

See
[this guide](https://github.com/Crow281/ts-monorepo-template/blob/main/doc/maintenance/template/Setup.md)
for how to setup your own project with this template.
